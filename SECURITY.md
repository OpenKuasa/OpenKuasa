# Security Policy

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or
discussion.

Report them privately through GitHub instead:

1. Go to the repository's
   [Security tab](https://github.com/OpenKuasa/OpenKuasa/security).
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what an attacker could do
   with it.

Only the maintainers can see the report. We will reply there, work on a fix
with you, and credit you in the advisory unless you would rather not be named.

## What counts

Anything that lets someone read or change data they should not have access to,
sign in as someone else, get around tenant isolation, or run code on a server
or in another person's browser.

Ordinary bugs, including ones in the sign-in screens that have no security
impact, belong in a normal
[bug report](https://github.com/OpenKuasa/OpenKuasa/issues/new/choose).

## Supported versions

OpenKuasa has no numbered releases yet. Fixes are made on `main` only, so
self-hosted installs should stay up to date with it.
