Weekly Studio is Jebat's AI agent. Each run reads your recent leads, campaigns and appointments, writes a short digest for you, and makes a poster, a hero image and a short video while the run stays under its cost cap.

## Who can do this

- Owners and admins can turn Weekly Studio on or off, choose its **Cadence** and set its **Cost cap per run (RM)**.
- Owners, admins and members can click **Run now**.
- Viewers can see the settings and the run history, but cannot change or run anything. The demo workspace cannot run it.

## Before you start

Weekly Studio runs on your workspace's own AI key. Without one, a run fails. See [Add your OpenRouter key](/docs/getting-started/openrouter-key).

## Steps

1. Open **Jebat** and choose **AI Agents** in the side menu.
2. In the **Weekly Studio** card, turn the switch on. Its label changes from **Disabled** to **Enabled**.
3. Choose a **Cadence**: **Off**, **Daily** or **Weekly**. Daily or Weekly sets up a schedule that runs it every day or every week, starting one day or one week from now. Off stops that schedule.
4. Type a **Cost cap per run (RM)**, from RM 0 to RM 100, then click outside the box to save it. A run stops making images and video before it would go over this cap.
5. To run it straight away, click **Run now**.
6. Under **Run history**, find the run. Each run shows its status (**Running**, **Done**, **Failed** or **Skipped**), when it started, what it cost and how many assets it made.
7. Click the digest's first line to read the whole digest. The poster, the hero image and the video show under it once they are ready.

## Common problems

- **"Weekly Studio is turned off. An owner or admin can turn it on."** Ask an owner or admin to turn the switch on.
- **"The workspace daily spend cap has been reached…" or "The workspace weekly spend cap has been reached…"** The workspace has spent its daily or weekly allowance. See [Set Weekly Studio's schedules and spend caps](/docs/jebat/agent-schedules).
- **"A run is already in progress. Please wait for it to finish."** A workspace runs one Weekly Studio run at a time.
- **"Enter a cost cap between RM 0 and RM 100."** The cost cap must be within that range.
- **"Video rendering…"** The video takes longer than the rest of the run. Come back to the page later.
- **"Poster could not be generated" or "Hero image could not be generated".** That step failed. The digest and anything else the run made are kept.
- **A run shows Skipped.** A scheduled run is skipped when nothing new has come into your leads, campaigns or appointments since the last run. It costs nothing.
